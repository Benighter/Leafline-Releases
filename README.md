# Leafline for Windows

[Download the latest Windows release](https://github.com/Benighter/Leafline-Releases/releases/latest)

Leafline is a Windows ebook library and reader with categories, favorites, notes, highlights, bookmarks, text search, Windows read-aloud, and complete library backups. It reads EPUB, MOBI, AZW3, PDF, FB2, TXT, CBZ, CBR and ZIP files.

This repository contains official installers and signed update metadata. Application source is maintained privately. Automatic updates verify the app identity, version, size, SHA-256 and Ed25519 release signature before installation.

Update feed: `https://raw.githubusercontent.com/Benighter/Leafline-Releases/main/leafline-update.json`
